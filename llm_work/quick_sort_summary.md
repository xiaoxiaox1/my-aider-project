# 快速排序实现概览

本项目包含三种快速排序实现，各有特点，适用于不同场景。

## 1. `quick_sort`（基础递归版）

- **特点**：简洁易懂，使用列表推导式实现，返回新列表。
- **时间复杂度**：平均 O(n log n)，最坏 O(n²)
- **空间复杂度**：O(n)（递归栈 + 新列表）
- **适用场景**：教学演示、小数据量、对原数组无修改要求
- **优点**：代码简洁，逻辑清晰
- **缺点**：内存开销大，对已排序数据性能差

```python
sorted_list = quick_sort([64, 34, 25, 12, 22, 11, 90])
```

## 2. `optimized_quick_sort`（三数取中 + 插入排序优化）

- **特点**：传统快排优化版，使用三数取中选择基准，小数组用插入排序。
- **时间复杂度**：平均 O(n log n)，最坏 O(n²)（但极少见）
- **空间复杂度**：O(log n)（递归栈）
- **适用场景**：通用排序，性能要求较高
- **优点**：在大多数情况下表现优异，对已排序数据鲁棒
- **缺点**：实现稍复杂，仍可能退化为 O(n²)

```python
arr = [64, 34, 25, 12, 22, 11, 90]
optimized_quick_sort(arr)
```

## 3. `dual_pivot_quick_sort`（双基准快排）

- **特点**：使用两个基准值，将数组分为三段，由 Yaroslavskiy 提出，Java 7+ 默认使用。
- **时间复杂度**：平均 O(n log n)，最坏 O(n²)（但更难触发）
- **空间复杂度**：O(log n)
- **适用场景**：大规模数据排序，对性能要求极高
- **优点**：在多数数据上比传统快排快 10%-20%，尤其对已排序数据
- **缺点**：实现最复杂，对小数组优化不如其他版本

```python
arr = [64, 34, 25, 12, 22, 11, 90]
dual_pivot_quick_sort(arr)
```

## 性能对比建议

| 场景 | 推荐实现 |
|------|----------|
| 教学/演示 | `quick_sort` |
| 通用排序 | `optimized_quick_sort` |
| 大数据量/高性能 | `dual_pivot_quick_sort` |

> ✅ **建议**：生产环境优先使用 `dual_pivot_quick_sort`，兼顾性能与稳定性。
